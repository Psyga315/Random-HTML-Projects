Guess the Character
Two players. Two secret characters. One pie.
Each player can see the other's character, but not their own.

How it works: the host announces a shared trait and secretly gives each player a character. Each player asks yes/no questions about their own character, and the opponent (who can see it) answers. A yes keeps your turn, a no passes it. Name your character to score. Loser gets pied.

Open ⚙ Setup to add an API key, pick models, or take a seat yourself. Or:

The demo uses a tiny built-in fake model (no API calls) so you can see the interface.

Setup

Connection

Requests go straight from your browser to the API; nothing else sees your key. Get one at openrouter.ai/keys. Type demo as any model name to use the free fake model.

Contestants

If you take a seat, that player's model is ignored, the host must be an AI, and the answer-key check is skipped (it would show you your own character).

"Can see images" matters for the drawing lifeline. Auto-detect asks OpenRouter's model list; on other servers, set it yourself.

Rules

A drawing reaches the guesser as the picture itself (if it can see images), as a written description by a model that can, or as an emoji drawing if no model in the game can see images.

You're the host

The players never see this screen. Pick one shared trait, then a character for each player that fits it.

Check the answer keys

Each answerer wrote down what it knows about the character it will answer for. These notes decide every answer it gives, and whatever you leave in is treated as true, so fix anything that's wrong or missing. Keep the "Also known as:" line, because those names get bleeped. Players never see this.
